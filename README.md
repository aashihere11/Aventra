# Aventra - Stock Trading Platform

A beginner-friendly stock trading simulator built with React, 
inspired by Zerodha's UI.

## About
Aventra helps first-time investors understand how a real trading 
platform works — without risking real money. Users can practice 
buying and selling stocks using virtual funds in a simulated 
environment.

The goal is simple — build confidence before investing a single 
real rupee.

## Features
- Landing page with company info
- User login and authentication
- Dashboard to manage virtual portfolio
- Add virtual funds to your account
- Buy and sell real stocks (live prices via API)
- Transaction history tracking
- Payment API integration for fund simulation

## Tech Stack
- React
- Bootstrap
- JavaScript

## APIs Used
- [Finnhub](https://finnhub.io) — real-time US stock market prices
- [Razorpay](https://razorpay.com) — payment gateway for fund simulation prices
- Payment API — for fund management
